# Fantasy football dashboard — session notes

Date: September 17, 2026

## Goal

Create a daily-use dashboard for the user's own Yahoo fantasy football team and its 12-team league: compare rosters, standings and matchups; eventually support start/sit and trade decisions, player value trends, and injury awareness. Keep the first version local and read-only.

## Data collected from Yahoo

- League: 12 teams. Yahoo says “not a cash league”; the user confirmed the $20 entry pot is handled privately outside Yahoo.
- Format: full PPR (1 point per reception); 25 passing yards per point; passing TD +4; interception −1; 10 rushing/receiving yards per point; rushing/receiving TD +6; 2-point conversion +2; fumble lost −2; long-play bonuses apply.
- Lineup: QB, 2 RB, 2 WR, TE, W/R/T, Q/W/R/T, K, DEF; 6 bench and 2 IR slots.
- All 12 roster pages were reviewed read-only, including starters, bench, and IR. The exact roster dataset is embedded in `../league-room.html`; use that file as the roster source of truth.
- User team is identified in the dashboard as “Your Team.” Yahoo’s rank/record snapshot showed 11th, 0–1, while Week 2 was in progress. Scores and displayed starters were live and could change.

## Current artifact and boundaries

`../league-room.html` is a self-contained dashboard that can be opened in a browser. It has overview, standings, roster filters, live-snapshot matchups, scoring settings, and a basic trade roster-fit comparison. It does not connect to Yahoo or fetch live scores, projections, news, trends, or injuries. It should not claim a trade is fair or make unsupported start/sit calls.

## Weekly decisions added

- The Weekly decisions page now allows manually entered injury status, trend, and projected points for a selected team. Projections are stored per week, with browser-local storage and JSON export/import for backup or transfer.
- A start/sit comparison checks the user's eligible bench players against starters using only entered projections and injury labels. It flags starters marked doubtful/out/IR; it does not claim the values are independent recommendations.
- The trade comparison can show a one-week projection difference when both players have entered projections, clearly marked as unsuitable for season-long trade valuation.
- No live projections, medical news, injury reports, or Yahoo connection are active.

## Manual roster editor added

- `Manage roster` is an editable local copy separate from the fixed original Yahoo snapshot. Waiver pickups can be entered by name/position; drops remove the player from the local roster; trades transfer one player each way between Your Team and another tracked team.
- The user can change their player's position and starter/bench/IR status. Changes persist in browser storage and affect roster views and the trade lab; standings records, scores, and matchups remain the captured snapshot.
- A dated change log allows undoing the latest roster change. Import/export provides a portable roster and move-history backup. Reset to Yahoo snapshot requires confirmation.
- Real Yahoo transactions are never submitted. Browser storage may not be available for local-file pages, so the user should export backups.
- Validation: JavaScript syntax check and a Node harness verified startup roster counts, pickup, drop/undo, two-sided trade/undo, persistence writes, backup validation, and duplicate-player rejection. A live Safari walkthrough added a temporary demo player, dropped it, exercised undo, then undid the temporary add; the final state is back to the original 17-player roster with an empty move log. The walkthrough also caught and fixed a UTC/local-date mismatch.

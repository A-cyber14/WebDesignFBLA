About

One trusted place to find help in Pinellas.

Our mission

Make every essential Pinellas County resource easy to find, understand, and trust.

Why it exists

Help in Pinellas is spread across dozens of county pages, nonprofit sites, and PDFs. Pinellas Connect puts verified services in one searchable place. When we can't answer a question, we point people to 211.

How information is maintained

  • Every listing is checked against an official source and dated.
  • If a source doesn't state hours or costs, we say “Not listed.” We never guess.
  • Map pins come from geocoded street addresses, never hand placement.
  • Events come from official calendars and disappear after they end.

How it's built
  • Plain HTML, CSS, and JavaScript. No framework or build step.
  • All listings live in one data file, so every page stays in sync.
  • Built to WCAG 2.2 AA: keyboard access, visible focus, labeled fields, list view for the map, reduced-motion support.
  • Leaflet with OpenStreetMap tiles: free, with no API key.
